# Формат промпта - один параграф

## Изменения

Промпт теперь генерируется в **один параграф без переносов строк**, но с правильными знаками препинания.

## Что было изменено

### 1. Убраны переносы строк
- Все части промпта объединяются через пробел, а не через `\n\n`
- Системный промпт очищается от переносов строк
- Negative prompt больше не начинается с `\n`

### 2. Правильные знаки препинания
- Каждая часть промпта заканчивается точкой
- Между частями - пробел
- Внутри частей - запятые для перечисления

### 3. Финальная очистка
- Убираются лишние пробелы
- Убираются переносы строк
- Текст выравнивается

## Структура промпта

```
[Системный промпт]. [Стиль и тип]. [Композиция]. [Объект]. [Эмоция и поза]. [Настроение]. [Окружение]. Negative prompt: [список].
```

## Преимущества формата

### 1. Совместимость с AI-моделями
- Некоторые AI-модели лучше работают с одним параграфом
- Уменьшается вероятность неправильной интерпретации переносов строк
- Более компактный формат

### 2. Удобство копирования
- Проще скопировать весь промпт целиком
- Не нужно выделять несколько абзацев
- Меньше шансов пропустить часть текста

### 3. Читаемость
- Знаки препинания сохраняют структуру
- Точки разделяют логические части
- Запятые разделяют элементы внутри частей

## Технические детали

### Очистка системного промпта
```typescript
const cleanSystemPrompt = data.systemPrompt
  .replace(/\n/g, ' ')      // Заменяем переносы на пробелы
  .replace(/\s+/g, ' ')     // Убираем лишние пробелы
  .trim();                   // Убираем пробелы в начале и конце
```

### Объединение частей
```typescript
const finalPrompt = paragraphs
  .join(' ')                 // Объединяем через пробел
  .replace(/\n/g, ' ')      // Убираем переносы
  .replace(/\s+/g, ' ')     // Убираем лишние пробелы
  .trim();                   // Убираем пробелы в начале и конце
```

## Проверка формата

### Тест 1: Один параграф
1. Заполните все поля
2. Нажмите "✨ Генерировать промпт"
3. Проверьте, что промпт отображается в одну строку (без переносов)
4. Скопируйте промпт и вставьте в текстовый редактор
5. Убедитесь, что это один параграф

### Тест 2: Знаки препинания
1. Сгенерируйте промпт
2. Проверьте, что:
   - Каждая часть заканчивается точкой
   - Между частями есть пробел
   - Нет двойных пробелов
   - Нет переносов строк

### Тест 3: Системный промпт
1. Выберите пресет системного промпта
2. Сгенерируйте промпт
3. Проверьте, что системный промпт:
   - Не содержит переносов строк
   - Заканчивается точкой
   - Правильно отделён пробелом от следующей части

### Тест 4: Копирование
1. Сгенерируйте промпт
2. Нажмите "📋 Копировать"
3. Вставьте в текстовый редактор
4. Убедитесь, что это один параграф без переносов

## Известные ограничения

1. **Длинные промпты**: Очень длинные промпты могут быть неудобны для чтения в одну строку
2. **AI-модели**: Некоторые модели могут лучше работать с структурированным текстом (с переносами)
3. **Редактирование**: Сложнее редактировать конкретную часть промпта в одной длинной строке

## Рекомендации

### Когда использовать один параграф:
- Для AI-моделей, которые лучше работают с компактным текстом
- Для быстрого копирования и вставки
- Для отправки промпта в мессенджеры или email

### Когда использовать структурированный текст:
- Для ручного редактирования промпта
- Для AI-моделей, которые лучше понимают структурированный текст
- Для документации и примеров

## Обратная совместимость

Если вам нужен старый формат с переносами строк, вы можете:
1. Скопировать промпт
2. Вставить в текстовый редактор
3. Добавить переносы строк вручную после каждой точки

Или изменить код в `src/App.tsx`:
```typescript
// Измените:
setGeneratedPrompt(finalPrompt);

// На:
setGeneratedPrompt(paragraphs.join('\n\n'));
```
