# Упрощение дистанций и удаление формата

## Что изменилось

### 1. Упрощены описания дистанций

Убраны упоминания "воздуха" и лишних деталей. Теперь описания конкретные и понятные для AI-моделей.

**Было:**
```
Средний план — объект виден целиком или до середины, вокруг есть воздух
Общий план — объект в контексте окружения, вокруг очень много воздуха
```

**Стало:**
```
Средний план — объект виден до середины
Общий план — объект виден целиком с окружением
Дальний план — объект виден целиком, окружение доминирует
```

**Полный список дистанций:**
1. **Макро план** — видны мельчайшие детали и текстуры
2. **Крупный план** — объект занимает большую часть кадра
3. **Средне-крупный план** — объект показан до плеч
4. **Средний план** — объект виден до середины
5. **Средне-дальний план** — объект показан полностью
6. **Общий план** — объект виден целиком с окружением
7. **Дальний план** — объект виден целиком, окружение доминирует

### 2. Удалён формат изображения

Удалены:
- Поле `format` из `PromptData`
- Массив `formatOptions` (1:1, 4:3, 3:2, 16:9, 9:16, 2:3, 3:4, 5:4, 21:9)
- UI элемент для выбора формата
- Генерация "нарисуй [формат]" в промпте
- Все упоминания формата в `resetForm` и `generateRandomPrompt`

**Причина удаления:**
- AI-модели не понимают форматы типа "1:1", "2:3"
- Формат не влияет на качество генерации
- Лишний параметр, который не даёт результата

## Преимущества изменений

### 1. Более понятные описания для AI
- Убраны абстрактные понятия ("воздух")
- Конкретные описания того, что видно в кадре
- AI модели лучше понимают прямые инструкции

### 2. Меньше путаницы
- Удалён формат, который AI не понимает
- Проще структура промпта
- Меньше параметров для обработки

### 3. Лучший результат
- AI модели точнее понимают, что рисовать
- Меньше лишних деталей на фото
- Более предсказуемый результат

## Технические изменения

### Удалённые элементы:
1. `format: string` из `PromptData`
2. `formatOptions` массив
3. UI компонент для выбора формата
4. Генерация `нарисуй ${data.format}`
5. Все упоминания `format` в `resetForm` и `generateRandomPrompt`

### Изменённые элементы:
1. `distanceOptions` - упрощены описания
2. Убраны упоминания "воздуха"
3. Упрощены формулировки

## Тестирование

### Тест 1: Проверка дистанций
1. Выберите разные дистанции (макро, крупный, средний, общий, дальний)
2. Сгенерируйте промпт
3. Проверьте, что описания конкретные и без "воздуха"

### Тест 2: Проверка отсутствия формата
1. Откройте интерфейс
2. Убедитесь, что нет поля "Формат изображения"
3. Сгенерируйте промпт
4. Проверьте, что в начале нет "нарисуй [формат]"

### Тест 3: Разные типы съёмки
1. Fashion + средний план → объект виден до середины
2. Портрет + крупный план → объект занимает большую часть кадра
3. Пейзаж + дальний план → объект виден целиком, окружение доминирует
4. Предметная съёмка + макро план → видны мельчайшие детали и текстуры

## Рекомендации по использованию

### Для портретов:
- **Крупный план** — акцент на лице и эмоциях
- **Средне-крупный план** — лицо и плечи
- **Средний план** — до середины тела

### Для fashion:
- **Средний план** — до середины, видна одежда
- **Средне-дальний план** — полностью, виден образ целиком
- **Общий план** — с окружением, виден контекст

### Для пейзажей:
- **Общий план** — объект с окружением
- **Дальний план** — объект маленький, окружение доминирует

### Для предметной съёмки:
- **Макро план** — мельчайшие детали
- **Крупный план** — объект занимает большую часть кадра
- **Средний план** — объект с небольшим окружением
