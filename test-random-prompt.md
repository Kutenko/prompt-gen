# Тестирование функции "Случайный промпт"

## Описание функции
Функция "Случайный промпт" автоматически заполняет все поля случайными значениями с учётом логических ограничений.

## Как работает

### 1. Логика выбора
- **Тип фотографии**: выбирается случайно из всех доступных типов
- **Объект**: выбирается случайно из объектов, совместимых с выбранным типом съёмки
- **Действие**: выбирается случайно из действий, совместимых с выбранным объектом
- **Остальные поля**: заполняются случайными значениями с вероятностью 30-70% быть пустыми

### 2. Вероятности пустых значений
Разные поля имеют разную вероятность быть пустыми для создания разнообразия:

**Высокая вероятность заполнения (70-100%):**
- Тип фотографии (100%)
- Объект (100%)
- Формат (100%)
- Ракурс (100%)

**Средняя вероятность заполнения (40-70%):**
- Журнал (50%)
- Стиль (40%)
- Художественный стиль (30%)
- Фильтр (40%)
- Возраст (70% для портретов)
- Причёска (70% для портретов)
- Цвет волос (70% для портретов)
- Макияж (60% для портретов)
- Одежда верх/низ (70% для портретов)
- Цвет одежды (70% для портретов)
- Головной убор (40% для портретов)
- Цвет головного убора (50% для портретов)
- Эмоция (70% для портретов)
- Поза (70% для портретов)
- Позиция в кадре (60%)
- Дальность (60%)
- Тон (70%)
- Освещение (70%)
- Фон (60%)
- Окружение (50%)
- Локация (40%)

**Низкая вероятность заполнения (0%):**
- Основной цвет (всегда пустое)
- Акцентный цвет (всегда пустое)
- Текстура (всегда пустое)

### 3. Логические ограничения

#### Тип съёмки → Объект
- **Предметная съёмка / Натюрморт**: только растения, еда, предметы, архитектура
- **Пейзаж / Архитектурная съёмка**: растения, архитектура, транспорт
- **Спортивная съёмка**: люди, транспорт
- **Портрет / Fashion / Стрит / Свадебная**: все объекты

#### Объект → Действие
- **Люди**: держит цветок, смотрит в окно, идёт по улице, сидит на стуле и т.д.
- **Животные**: бежит, сидит, стоит, лежит, играет, ест, спит и т.д.
- **Транспорт**: едет по дороге, стоит на парковке, мчится на скорости и т.д.
- **Растения**: цветёт, шелестит на ветру, растёт, покрыт росой и т.д.
- **Еда/напитки**: парит, тает, украшено фруктами, подаётся на тарелке и т.д.
- **Предметы**: лежит на поверхности, отражает свет, открыта, светится и т.д.
- **Архитектура**: возвышается, освещён закатным солнцем, отражается в воде и т.д.

#### Портретный тип → Специальные поля
Только для портретных типов съёмки (Портрет, Fashion, Стрит, Свадебная) заполняются:
- Возраст
- Причёска и цвет волос
- Макияж
- Одежда (верх/низ) и цвета
- Головной убор и цвет
- Эмоция
- Поза
- Части тела в кадре

Для непортретных типов эти поля остаются пустыми, но заполняется "Фокус на объекте".

## Примеры использования

### Тест 1: Базовая генерация
1. Нажать кнопку "🎲 Случайный"
2. Проверить, что все поля заполнены
3. Нажать "✨ Генерировать промпт"
4. Проверить, что промпт сгенерирован корректно

### Тест 2: Предметная съёмка без людей
1. Нажать кнопку "🎲 Случайный" несколько раз
2. Если выпала "Предметная съёмка", проверить, что объект НЕ человек/животное
3. Проверить, что действие совместимо с объектом

### Тест 3: Портрет с полной экипировкой
1. Нажимать "🎲 Случайный" до тех пор, пока не выпадет портретный тип
2. Проверить, что заполнены поля: возраст, причёска, макияж, одежда, эмоция, поза
3. Сгенерировать промпт и проверить корректность

### Тест 4: Разнообразие результатов
1. Нажать "🎲 Случайный" 10 раз
2. Каждый раз генерировать промпт
3. Проверить, что результаты разные
4. Проверить, что некоторые поля иногда пустые

### Тест 5: Логическая совместимость
1. Сгенерировать случайный промпт
2. Проверить:
   - Если объект "Дерево", то действие НЕ "держит чашку"
   - Если тип "Предметная съёмка", то объект НЕ "Женщина"
   - Если объект "Собака", то действие из списка для животных
   - Если тип портретный, то заполнены поля внешности

## Ожидаемое поведение

### ✅ Правильно:
- Каждый клик по "🎲 Случайный" генерирует новые случайные значения
- Логические ограничения соблюдаются
- Некоторые поля могут быть пустыми
- Портретные типы имеют больше заполненных полей
- Действия соответствуют выбранным объектам

### ❌ Неправильно:
- Все поля всегда заполнены
- Люди в предметной съёмке
- Дерево держит чашку
- Портретный тип без полей внешности
- Одинаковые результаты при каждом клике

## Технические детали

### Функция randomChoice
```typescript
const randomChoice = <T,>(arr: T[]): T => 
  arr[Math.floor(Math.random() * arr.length)];
```

### Функция randomChoiceWithEmpty
```typescript
const randomChoiceWithEmpty = <T,>(arr: T[], emptyProbability: number = 0.3): T | '' => {
  return Math.random() < emptyProbability ? '' : randomChoice(arr);
};
```

## Интеграция с существующей логикой

Функция `generateRandomPrompt` использует существующие функции:
- `getAvailableObjects(photoType)` - для получения совместимых объектов
- `getAvailableActions(object)` - для получения совместимых действий
- `setData()` - для установки сгенерированных значений

После генерации случайных значений пользователь может:
1. Отредактировать любые поля вручную
2. Сгенерировать промпт кнопкой "✨ Генерировать промпт"
3. Сбросить все поля кнопкой "🔄 Сбросить"
4. Сгенерировать новый случайный промпт

## Цветовая схема кнопки

Кнопка "🎲 Случайный" имеет градиент от синего к циановому:
```css
bg-gradient-to-r from-blue-600 to-cyan-600 
hover:from-blue-500 hover:to-cyan-500
shadow-blue-500/20
```

Это отличает её от других кнопок:
- "✨ Генерировать промпт" - фиолетово-розовый градиент
- "🔄 Сбросить" - серый фон с рамкой
