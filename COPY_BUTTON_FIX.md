# Исправление кнопки копирования для десктопа

## Проблема

Кнопка копирования работала только на мобильных устройствах, но не на десктопе.

## Причина

1. **Clipboard API** требует HTTPS или localhost для работы
2. **execCommand('copy')** устарел и может не работать в некоторых браузерах
3. Отсутствие fallback-методов для различных окружений
4. Нет обратной связи с пользователем при ошибке

## Решение

Реализована многоуровневая система копирования с тремя методами и модальным окном для ручной инструкции.

### Метод 1: Modern Clipboard API
```typescript
if (navigator.clipboard && window.isSecureContext) {
  await navigator.clipboard.writeText(generatedPrompt);
  setCopied(true);
  setTimeout(() => setCopied(false), 2000);
  return;
}
```

**Условия работы:**
- Поддерживается браузером
- Сайт открыт по HTTPS или localhost
- Пользователь дал разрешение на доступ к буферу обмена

**Преимущества:**
- Современный стандарт
- Работает асинхронно
- Не требует выделения текста

### Метод 2: Fallback через textarea и execCommand
```typescript
const textArea = document.createElement('textarea');
textArea.value = generatedPrompt;
textArea.style.position = 'fixed';
textArea.style.opacity = '0';
// ... другие стили для скрытия

document.body.appendChild(textArea);
textArea.focus();
textArea.select();
textArea.setSelectionRange(0, generatedPrompt.length);

const successful = document.execCommand('copy');
document.body.removeChild(textArea);
```

**Условия работы:**
- Браузер поддерживает execCommand
- Есть доступ к DOM
- Нет блокировки со стороны расширений браузера

**Преимущества:**
- Работает в большинстве браузеров
- Не требует HTTPS
- Совместимость со старыми браузерами

### Метод 3: Альтернативный fallback через selection
```typescript
const textArea = document.createElement('textarea');
textArea.value = generatedPrompt;
textArea.style.position = 'absolute';
textArea.style.left = '-999999px';
textArea.setAttribute('readonly', '');

document.body.appendChild(textArea);

// Сохраняем текущее выделение
const selected = document.getSelection()?.rangeCount ? 
  document.getSelection()!.getRangeAt(0) : null;

textArea.select();
textArea.setSelectionRange(0, generatedPrompt.length);

const successful = document.execCommand('copy');
document.body.removeChild(textArea);

// Восстанавливаем выделение
if (selected) {
  document.getSelection()?.removeAllRanges();
  document.getSelection()?.addRange(selected);
}
```

**Условия работы:**
- Браузер поддерживает Selection API
- Есть доступ к DOM
- Пользователь не заблокировал выделение текста

**Преимущества:**
- Сохраняет текущее выделение пользователя
- Работает даже если первый метод не сработал
- Более надёжный для десктопных браузеров

### Метод 4: Модальное окно с инструкцией

Если все три метода не сработали, показывается модальное окно с инструкцией:

```typescript
const modal = document.createElement('div');
modal.innerHTML = `
  <h2>Не удалось скопировать автоматически</h2>
  <p>Пожалуйста, скопируйте промпт вручную:</p>
  <ol>
    <li>Закройте это окно</li>
    <li>Выделите текст промпта мышью</li>
    <li>Нажмите Ctrl+C (или Cmd+C на Mac)</li>
  </ol>
  <button>Понятно</button>
`;
```

**Преимущества:**
- Пользователь всегда получает обратную связь
- Понятная инструкция
- Возможность скопировать вручную

## Известные ограничения

### 1. HTTPS требуется для Clipboard API
**Проблема:** Clipboard API не работает по HTTP (кроме localhost)

**Решение:** Используются fallback-методы через execCommand

### 2. Расширения браузера могут блокировать копирование
**Проблема:** Некоторые расширения блокируют доступ к буферу обмена

**Решение:** Показывается модальное окно с инструкцией

### 3. Старые браузеры
**Проблема:** Очень старые браузеры могут не поддерживать все методы

**Решение:** Показывается модальное окно с инструкцией

### 4. Режим инкогнито
**Проблема:** В режиме инкогнито могут быть ограничения на доступ к буферу обмена

**Решение:** Используются fallback-методы

## Рекомендации для пользователей

### Если кнопка не работает:

1. **Проверьте протокол**
   - Убедитесь, что сайт открыт по HTTPS
   - Или используйте localhost для тестирования

2. **Откройте консоль**
   - Нажмите F12
   - Перейдите на вкладку Console
   - Проверьте логи для диагностики

3. **Попробуйте другой браузер**
   - Chrome, Firefox, Edge, Safari
   - Каждый браузер имеет свои особенности

4. **Отключите расширения**
   - Некоторые расширения могут блокировать копирование
   - Попробуйте отключить их временно

5. **Используйте ручное копирование**
   - Выделите текст промпта мышью
   - Нажмите Ctrl+C (или Cmd+C на Mac)
   - Вставьте в редактор (Ctrl+V или Cmd+V)
