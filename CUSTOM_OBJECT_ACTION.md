# Добавлена возможность ввода своих вариантов для Объекта и Действия

## Что изменилось

### Поля "Объект" и "Действие объекта" теперь поддерживают ввод своих вариантов

Ранее можно было только выбирать из предустановленного списка. Теперь добавлена опция "✏️ Свой вариант...", которая позволяет ввести произвольное значение.

## Как это работает

### Для поля "Объект":
1. Откройте выпадающий список
2. Выберите опцию "✏️ Свой вариант..."
3. Появится текстовое поле
4. Введите свой объект (например: "красный велосипед", "старый дуб", "горный пейзаж")
5. Введённое значение будет использовано в промпте

### Для поля "Действие объекта":
1. Откройте выпадающий список
2. Выберите опцию "✏️ Свой вариант..."
3. Появится текстовое поле
4. Введите своё действие (например: "медленно вращается", "светится в темноте", "отражается в воде")
5. Введённое значение будет использовано в промпте

## Пример использования

### Пример 1: Свой объект
**Выбрано:**
- Объект: ✏️ Свой вариант → "старый маяк на скале"
- Действие: ✏️ Свой вариант → "стоит в шторме"

**Результат в промпте:**
```
На фотографии — старый маяк на скале, стоит в шторме, ...
```

### Пример 2: Комбинация стандартного и своего
**Выбрано:**
- Объект: Женщина (из списка)
- Действие: ✏️ Свой вариант → "держит старый фотоаппарат и смотрит вдаль"

**Результат в промпте:**
```
На фотографии — Женщина, держит старый фотоаппарат и смотрит вдаль, ...
```

### Пример 3: Полный кастом
**Выбрано:**
- Объект: ✏️ Свой вариант → "заброшенный замок в тумане"
- Действие: ✏️ Свой вариант → "возвышается над долиной"

**Результат в промпте:**
```
На фотографии — заброшенный замок в тумане, возвышается над долиной, ...
```

## Технические детали

### Компонент SelectWithCustom
Создан универсальный компонент `SelectWithCustom`, который:
- Отображает выпадающий список с предустановленными вариантами
- Добавляет опцию "✏️ Свой вариант..." в конец списка
- При выборе этой опции показывает текстовое поле
- Позволяет переключаться между списком и вводом
- Сохраняет введённое значение в состоянии

### Логика работы
```typescript
const [isCustom, setIsCustom] = useState(false);
const [customValue, setCustomValue] = useState('');

// При выборе из списка
if (selectedValue === '__custom__') {
  setIsCustom(true);
  setCustomValue('');
} else {
  setIsCustom(false);
  onChange(selectedValue);
}

// При вводе своего значения
const handleCustomChange = (e: React.ChangeEvent<HTMLInputElement>) => {
  setCustomValue(e.target.value);
  onChange(e.target.value);
};
```

## Преимущества

1. **Гибкость** — можно указать любой объект или действие, даже если его нет в списке
2. **Удобство** — не нужно искать подходящий вариант, можно сразу ввести что нужно
3. **Совместимость** — работает с логикой фильтрации объектов по типу съёмки
4. **Простота** — интерфейс интуитивно понятен, опция "Свой вариант" явно обозначена

## Ограничения

- При смене типа фотографии список доступных объектов обновляется, но введённое вручную значение сохраняется
- Действия не фильтруются по кастомным объектам (только по стандартным из списка)
- Если выбрать стандартный объект после ввода кастомного, кастомное значение будет перезаписано

## Тестирование

### Тест 1: Ввод своего объекта
1. Выберите тип съёмки: "Пейзаж"
2. В поле "Объект" выберите "✏️ Свой вариант..."
3. Введите: "вулкан с лавой"
4. Сгенерируйте промпт
5. **Ожидаемый результат**: В промпте должно быть "вулкан с лавой"

### Тест 2: Ввод своего действия
1. Выберите объект: "Дерево" (из списка)
2. В поле "Действие объекта" выберите "✏️ Свой вариант..."
3. Введите: "шелестит листьями на ветру"
4. Сгенерируйте промпт
5. **Ожидаемый результат**: В промпте должно быть "Дерево, шелестит листьями на ветру"

### Тест 3: Переключение между списком и вводом
1. Выберите объект из списка: "Женщина"
2. Переключитесь на "✏️ Свой вариант..."
3. Введите: "девушка в красном платье"
4. Вернитесь к выбору из списка
5. **Ожидаемый результат**: Текстовое поле должно исчезнуть, значение из списка должно быть выбрано

### Тест 4: Кастомный объект + стандартное действие
1. Введите свой объект: "робот"
2. Выберите действие из списка: "стоит"
3. Сгенерируйте промпт
4. **Ожидаемый результат**: "робот, стоит"

### Тест 5: Полный кастом
1. Введите свой объект: "космический корабль"
2. Введите своё действие: "летит сквозь облака"
3. Сгенерируйте промпт
4. **Ожидаемый результат**: "космический корабль, летит сквозь облака"
