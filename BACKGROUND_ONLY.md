# Удаление окружения и локации, расширение фонов

## Что изменилось

### 1. Удалены поля "Окружение" и "Локация"

Полностью удалены:
- Поля `environment` и `location` из `PromptData`
- Массивы `environmentOptions` и `locationOptions`
- Объекты `environmentDescriptions` и `locationDescriptions`
- UI секции для выбора окружения и локации
- Генерация этих полей в промпте
- Все упоминания в `resetForm` и `generateRandomPrompt`

**Причина удаления:**
- AI-модели лучше понимают один параметр "Фон" вместо трёх
- Упрощение структуры промпта
- Меньше путаницы для AI

### 2. Расширены варианты фонов

Добавлено 20 новых вариантов фонов с детальными описаниями:

**Новые варианты:**
- Звёздное небо
- Северное сияние
- Грозовое небо
- Радуга
- Лунный свет
- Водопад
- Океанские волны
- Снежные горы
- Цветущие сады
- Осенние листья
- Зимний лес
- Весенние цветы
- Летнее поле
- Пустынные дюны
- Тропический пляж
- Вулкан
- Каньон
- Пещера
- Болото
- Тундра

**Всего вариантов фона:** 35 (было 15)

### 3. Добавлена возможность ввода своего варианта

Поле "Фон" теперь использует компонент `SelectWithCustom`, который позволяет:
- Выбрать из 35 предустановленных вариантов
- Или ввести свой вариант через опцию "✏️ Свой вариант..."

### 4. Расширены описания фонов

Все описания фонов теперь более детальные и красочные:

**Было:**
```
'Закатное солнце': 'закатное солнце с золотисто-оранжевой палитрой'
```

**Стало:**
```
'Закатное солнце': 'тёплое закатное солнце с золотисто-оранжевой палитрой, мягким светом и романтичной атмосферой уходящего дня'
```

## Преимущества изменений

### 1. Проще структура
- Одно поле "Фон" вместо трёх (Фон + Окружение + Локация)
- Меньше параметров для настройки
- Легче понять, что выбрать

### 2. Больше вариантов
- 35 вариантов фонов вместо 15
- Более детальные описания
- Возможность ввести свой вариант

### 3. Лучше для AI
- AI модели лучше понимают один параметр "Фон"
- Детальные описания помогают AI точнее генерировать
- Меньше путаницы с тремя похожими полями

### 4. Гибкость
- Можно выбрать из списка или ввести свой вариант
- Детальные описания помогают понять, что получится
- Больше креативности с кастомными вариантами

## Технические изменения

### Удалённые элементы:
1. `environment: string` из `PromptData`
2. `location: string` из `PromptData`
3. `environmentOptions` массив
4. `locationOptions` массив
5. `environmentDescriptions` объект
6. `locationDescriptions` объект
7. UI секции для environment и location
8. Генерация environment и location в промпте
9. Все упоминания в `resetForm` и `generateRandomPrompt`

### Изменённые элементы:
1. `backgroundOptions` - расширен с 15 до 35 вариантов
2. `backgroundDescriptions` - все описания стали детальнее
3. UI для background - заменён на `SelectWithCustom`
4. Название секции - изменено с "Окружение" на "Фон"
